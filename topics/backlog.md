# 주제 백로그

위에서부터 순서대로 쓴다. 다 쓴 주제는 `- [x] ... (YYYY-MM-DD)` 로 바꾼다.
비면 `posts/` 최근 글과 겹치지 않는 주제를 스스로 정해 쓴다.
**주제가 없다는 이유로 건너뛰는 것은 금지다.**

## 투자 마인드셋

- [ ] 손절 규칙을 정해두고도 매번 못 지키는 이유는 규칙이 나빠서가 아니라 규칙을 만든 순간의 나와 팔아야 하는 순간의 내가 다른 사람이기 때문이다
- [ ] 물타기와 분할매수는 실행이 똑같은데 왜 하나는 실수로 하나는 전략으로 불리는가
- [ ] 계좌를 매일 확인하는 습관이 수익률에 미치는 영향은 정보 획득이 아니라 감정 소모 쪽에 있다
- [ ] 오래 버텨서 번 돈과 안 팔아서 못 판 돈을 나는 구분하지 못한다
- [ ] 남의 수익 인증을 볼 때 생기는 조바심은 탐욕이 아니라 시간에 대한 불안이다
- [ ] 분산투자를 한다고 하면서 실제로는 같은 이야기를 믿는 종목만 모아둔 것은 아닌가
- [ ] 확신이 커질수록 비중을 늘리는 게 맞다고 배웠는데 확신의 크기와 정확도는 별개였다
- [ ] 하락장에서 아무것도 안 한 것을 인내라고 기록해도 되는가

## 투자할 때의 마음가짐

- [ ] 시장이 틀렸다는 판단은 대체로 내가 아직 모르는 정보가 있다는 신호였다
- [ ] 투자를 공부라고 부르면서 실제로는 이미 정한 결론의 근거만 모으고 있었다
- [ ] 목표 수익률을 정하는 일이 오히려 판단을 흐리게 만든 경우
- [ ] 잃어도 되는 돈이라는 말은 성립하지 않는다

## 독서에서 얻은 통찰

- [ ] 투자서를 읽고 밑줄 친 문장은 대개 이미 내가 하고 있던 행동을 정당화해주는 문장이었다
- [ ] 같은 책을 손실 중에 읽었을 때와 수익 중에 읽었을 때 완전히 다른 책이 되는 경험
- [ ] 책에서 배운 원칙이 실제로 작동하려면 원칙보다 그 원칙이 만들어진 상황을 알아야 했다

## 메모

- 항목은 문장 형태로 적는다. 명사 나열("분산투자")보다 각도가 담긴 한 문장이 좋은 입력이 된다.
- 새 주제를 추가할 때는 해당 섹션 아래 `- [ ]` 로 붙인다.
