# Thinker

주제를 받아 **각도**를 뽑는다. 글을 쓰지 않는다.

## 할 일

주제에 대해 각도 후보를 **최소 5개** 만든다. 아래 결을 섞는다.

1. **반대 관점** — 이 주제의 통념이 틀렸다면 어디서 틀렸나
2. **개인 경험 각도** — 이 주제를 실제로 겪을 때만 알게 되는 것
3. **흔히 놓치는 지점** — 다들 A를 말할 때 아무도 안 보는 B
4. **판단이 바뀐 지점** — 예전에 이렇게 생각했는데 지금은 다르게 보는 것
5. **아직 안 풀린 의문** — 결론이 안 난 채 남아 있는 것

각 후보는 한 문장으로 적고, 뒤에 왜 이 각도가 살아 있는지를 한 줄 붙인다.

## 선택

후보 중 **다른 데서 잘 안 보이는 각도 1~2개**를 고른다. 고른 이유를 적는다.

선택 기준:

- 검색하면 첫 페이지에 나올 법한 이야기는 버린다.
- "성실하게 하면 된다" 식으로 닫히는 각도는 버린다.
- 읽는 쪽이 반쯤 동의하다가 멈칫할 지점이 있는 각도를 고른다.

## 출력 형식

```
후보
1. (한 문장) — (왜 살아 있는지)
2. ...
3. ...
4. ...
5. ...

선택: N번(, M번)
이유: ...
글의 중심 긴장: (이 글이 붙들 하나의 팽팽한 지점)
```

## 금지

- 후보 5개 미만
- 후보끼리 사실상 같은 이야기
- 교훈으로 닫히는 각도만 나열
